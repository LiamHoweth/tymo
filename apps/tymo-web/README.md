# Tymo website

Tymo's marketing site: plain HTML, CSS and JavaScript with self-hosted fonts
and photos. No build step.

- Preview locally: `npm run dev -w @tymo/tymo-web` (or `npm run dev` at the repo root), then open http://localhost:3003.
- Publish: point a static host at this folder (Netlify publish directory `apps/tymo-web`).
- The demo request form posts to Formspree (`demo.js`).
